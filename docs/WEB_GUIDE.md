# Web 使用指南

## 快速上手

1. 打开 [Aster](http://127.0.0.1:8765)，选择 `Metabolomics`。想看公共数据和实验方案时，切换到 `Public Studies`。
2. 在“文献阅读”打开一篇论文。选一段方法文字，点击“询问选段”，试着追问作者的实验条件或方法局限。点击回答里的引用回到原文。
3. 将有用的摘录保存到笔记，写下自己的理解和待核对问题。在“问答”页可以跨当前项目的多篇论文和笔记提问。
4. 在“实验记录”保存方案、表格、附件和实际结果。在“论文写作”整理提纲，插入文献与记录引用。
5. 想建立自己的库时，点击项目选择器旁的 `+`，设置主题和术语，再导入自己的资料。项目概览的“导出”用于备份或迁移。

## 本机数据在哪里

以下路径相对于项目根目录 `/data_hdd/msj/mini-harness`。

| 路径 | 内容 |
| --- | --- |
| `.local/zhixu/zhixu.db` | 正在使用的 SQLite 库。存储项目、论文元数据、提取文本、引用、笔记版本、标注、实验记录及对话。`-wal` 和 `-shm` 由 SQLite 一起管理。 |
| `.local/zhixu/files/` | 阅读器实际打开的 PDF 和附件，按文件内容的 SHA-256 命名，由数据库关联原文件名和版本。 |
| `.local/zhixu/models/`、`.local/zhixu/indexes/` | BGE-M3、重排模型，以及检索用的向量和索引缓存。 |
| `.local/metabolomics/pdfs/`、`papers/` | 采集原件和复现导入所需的文件。`pdfs/` 存原始 PDF 与来源元数据，`papers/` 存 XML 与转换后的 Markdown。 |
| `.local/metabolomics/studies/`、`processed/` | 公开研究的元数据和处理矩阵。 |
| `.local/metabolomics/eval/`、`evaluation/` | 代谢组学评测题集与运行报告。旧示例检索集及其报告在 `.local/evaluation/`。 |
| `.local/bench-runtime/`、`.local/swebench-final/` | SWE-bench 离线运行环境和已修复的单题快照。 |

本机 Qwen 通过 `127.0.0.1:8000` 提供生成服务，权重在 `/data_hdd/msj/learning/qwen3.8-27b/models/`。GPU 检索服务使用 `127.0.0.1:8767`，模型路径由 `.local/metabolomics/retrieval-worker.json` 配置。

## 数据如何流转

导入文件时，Aster 保存原件、资料版本和逐页或分段文本。阅读器从文件目录读取原件，笔记和标注关联具体版本。提问时，mini-harness 调用所选模型，由模型按需查找授权资料。检索会对文本分块，结合 BM25 与向量召回，经 RRF 融合和重排选取证据。回答引用指向原文或记录版本，后续追问使用同一会话的历史。

## 启动

Python 3.12+、uv、Node.js 22.13+；启动后在设置中配置模型。

```sh
uv sync --locked --extra retrieval
source .venv/bin/activate
npm ci --prefix web
npm run build --prefix web
uv run --locked --extra retrieval aster
```

打开 http://127.0.0.1:8765。默认模型地址`http://127.0.0.1:8000/v1`，模型设置中选择服务实际提供的名称。

新安装使用`.local/aster`；本机已有`.local/zhixu`及`zhixu.db`继续保留。`ASTER_DATA_DIR`和`ASTER_DATABASE_URL`可覆盖路径；PostgreSQL迁移通过项目导出、恢复完成。

首次准备检索模型：`aster models --download`。本机已有BGE-M3与重排模型。可选GPU检索服务见实验指南；缺模型时显示降级状态。

## 文献阅读

1. 选择项目，进入“文献阅读”，导入PDF、TXT、Markdown或CSV（最大200 MB）。
2. 按标题、作者、DOI、标签搜索；按收藏和阅读状态筛选。
3. 点击“阅读”：左侧目录/搜索，中间正文，右侧笔记/标注/问答/信息。侧栏可收起、拖动宽度。
4. PDF与文字均连续滚动；目录、搜索、页码可直接跳转。关闭后恢复阅读位置。
5. 选中文字，可添加标注与评论、写笔记或将选段带入问答。点击标注可返回其原文版本。
6. 行末编辑资料信息，在“信息”修改标签与阅读状态；上传新版本后，旧标注和引用继续指向旧版。标注评论可修改或删除。

本机Metabolomics含300篇经PMC编号、DOI与校验值核验的原始PDF及XML文字全文。Public Studies是202项公开研究元数据，另有3份官方处理矩阵；未批量下载原始谱图。列表显示PDF / XML文本 / 研究元数据。

批注通过“加入笔记”保存为可检索的个人记录。标注保存在数据库，不写回PDF。扫描件和文字提取失败页仍显示原图，当前无OCR；问答读取文字，不自动分析图像。

## 笔记与论文写作

- 新建自由笔记、精读、想法、研究日志、组会、方法卡片、文献对照、论文提纲或审稿回复；可在现有正文末尾插入模板。
- “属性”设置类型、标签、置顶、关联文献和文档；关联文档中可插入固定版本引用，目标文档可查看反向关联。列表支持分类/标签筛选、搜索与卡片/列表切换。
- 支持标题、列表、任务清单、链接、引用、代码块、表格；粘贴表格保留字符串形式的科学计数法。Markdown源文可写`$公式$`、`$$公式$$`，在预览中排版。
- 修改后自动保存；Ctrl/⌘+S手动保存。未提交修改保留为浏览器草稿；版本冲突时先导出当前内容。
- 可上传图片、CSV、XLSX等附件；图片可预览，CSV可查看表格与描述统计。XLSX作为附件保存。
- “预览”中可点击引用；“历史版本”可查看旧稿或恢复内容为新版本；“导出”保存Markdown。
- “已核对”由本人确认，助手草稿不会自动确认。

## 实验记录

“实验日志”自由记录想法、过程、表格与附件；“方案与结果”管理明确的实验设计和执行记录。方案可自由编辑，结构化字段可选。记录结果时选择实际采用的方案版本，后续改方案不改变旧结果的关联。

“编辑结果”可修改条件、方案版本、正文和附件，保留旧稿。

本机Public Studies项目已有3份官方处理矩阵和3个待执行方案，尚未执行原始谱图重分析。

## 问答

- 日常助手由模型决定是否检索，不强制走七阶段流程。空库可讨论想法；问论文或自己的记录时使用RAG查证。“依据资料”强调来源，“自由讨论”允许展开建议。
- 默认查询本项目资料，可改为仅选定材料；论文阅读器内固定为正在阅读的论文版本。
- 可连续追问、切换历史对话、停止生成；需要保存产出时选择“保存为笔记/草稿”。
- 历史对话可重命名、删除和恢复。
- 个人观点、助手建议与论文证据分别处理，点击回答引用可核对出处。

## 模型与 Skills

- 设置→模型：可保存多组OpenAI兼容API、OpenAI API或Codex CLI配置；科研问答和PDF问答分别选择默认模型，每次对话也可临时切换。OpenAI API需手填模型名称；兼容服务的`auto`通过`/models`选择。Codex的输出tokens为长度参考，实际限制由CLI与模型服务控制。
- API Key仅保存在后端数据目录`model-keys.json`（权限600），或引用服务端环境变量；接口和项目备份不返回密钥。配置远程模型后，选中的资料会发送到该服务。
- Codex使用本机`codex login`后的登录，不需要在Web填写Key；首次启动检测到CLI时自动提供Codex选项。使用[官方非交互接口](https://developers.openai.com/codex/noninteractive)的临时只读会话，不加载用户插件，不开放Shell；检索工具由Aster执行。需本机安装支持`exec --ignore-user-config --ignore-rules --ephemeral --output-schema`的CLI；容器中默认不附带宿主机Codex登录。
- 设置→Skills：内置精读、文献对照、证据审阅、假设推敲、实验设计、论文写作、审稿回复；可复制修改、新建、停用、删除或导入/导出SKILL.md。助手可自动按需加载，也可在输入框指定。
- 技能只加载方法指令，不执行脚本，不自动获取上游技能的附属文件或数据库权限。自定义技能与模型配置是安装级设置；知识库备份保留已使用技能的运行快照，不迁移全局配置。

## 自定义知识库

新建项目或编辑项目，设置主题、术语/缩写、助手偏好及回答语言。代谢组学可用预设，也可改为任意领域；每个项目的材料、笔记、检索范围独立，导入自己的PDF/Markdown即可使用。已有项目的科研/通用类型保持不变，主题与术语可以随时编辑。

## 备份

项目首页“导出”保存资料、文档、标注、回收站和附件；侧栏“恢复项目备份”新建恢复项目。大文件备份通过临时文件传输，恢复限制4 GB压缩包 / 8 GB解压内容。全文、模型和本机数据不随源码发布。

## 删除与恢复

项目在“编辑项目”、资料在行末编辑窗口、文档在编辑器顶部、方案和结果在各自编辑窗口删除。上述记录进入侧栏“回收站”，从列表和新问答范围移除；恢复后保留版本和关联。旧引用仍可核对。删除方案会同时收起其结果；单独删除的旧结果不会随方案恢复。
